# Week 2 EDA Project 

Exploratory Data Analysis of an e-commerce dataset containing 1,200 transactions

###  What I Did

* Cleaned and explored the dataset using **Pandas**
* Analyzed product sales, revenue, order status, payment methods, and coupon usage
* Identified patterns and trends in the data
* Created **interactive visualizations with Plotly**
* Summarized key findings and business insights

### 🛠️ Tools

**Python | Pandas | NumPy | Plotly | Jupyter Notebook | Excel**

### 📈 Key Findings

* Printer had the highest number of transactions (**181**)
* Printer generated the highest revenue (**195,620.11**)
* Average order value was approximately **1,053.97**
* The dataset contained transactions from **2023–2025**
