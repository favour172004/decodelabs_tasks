
# Decodelabs Week 1: Data Cleaning

## Project Overview

This project was completed as part of the Decodelabs Data Analytics Internship. The objective of Week 1 was to inspect, clean, and prepare a dataset for further analysis.

## Dataset

The dataset contains 1,200 records and 14 columns covering customer orders, products, prices, payment methods, order statuses, and other order-related information.

## Data Cleaning Tasks

The following data cleaning activities were performed:

* Inspected the structure and contents of the dataset.
* Checked for missing values.
* Identified columns containing missing data.
* Checked for duplicate records.
* Reviewed data types and converted them where necessary.
* Examined numerical and categorical variables.
* Checked categorical values for consistency.
* Verified the dataset after the cleaning process.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Files

* `Dataset for Data Analytics.xlsx` - Original dataset provided for the project.
* `Cleaned_Dataset.xlsx` - Cleaned version of the dataset.
* `Week_1_Data_Cleaning.ipynb` - Jupyter Notebook containing the data inspection and cleaning process.

## Outcome

The dataset was cleaned and prepared for subsequent data analysis and exploratory data analysis.
